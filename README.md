# Nadav Levine

I ship real products by directing AI agents, and I improve them by watching real users.
I decide what to build, direct Claude Code to write it, and review every change before it ships.
Then I put it in front of real people, watch where they get stuck, and fix that next.

## Projects

- **[Inside Joke](https://insidejoke.vercel.app)**: a live party game for friend groups, played on phones with a shared TV. About 22 players and 300+ rounds so far. [How it's built](https://github.com/nadavlevine09/inside-joke-showcase)
- **[ContextKeeper](https://github.com/nadavlevine09/contextkeeper)**: local memory for Claude. It stores facts on your own computer and pulls the relevant ones into Claude Desktop through an MCP server.
- **[News-sentiment trading bot](https://github.com/nadavlevine09/trading-bot)**: a Python paper-trading system that scores headlines with FinBERT and trades through Alpaca. Two 90-day backtests (−0.91% and +4.28%) that I traced to market conditions.
- **[BagPath](https://github.com/nadavlevine09/bagpath)**: a suitcase attachment that follows its owner using a HuskyLens camera and an Arduino. I wrote the tracking code on a team of four. 1st Place, Best Use of AI/ML, CIJE Innovation Day 2026.
- **[Nely](https://github.com/nadavlevine09/nely)**: a Claude skill that reviews a college application the way one school's admissions office would, using that school's current, cited data.

Currently learning: SQL and data fundamentals.
